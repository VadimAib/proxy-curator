First launch setup

A few steps before the first run — you can cancel at any time.

  1. • Download cores xray and sing-box, about 110 MB on the first download.
  2. • Check the cores A short self-test through both engines.
  3. • Check the network Make sure a VPN/TUN client is not hijacking DNS.
  4. • Measure the channel CPU, network and disk — about 15–30 seconds.
  5. • Apply safe settings Only speed-test sizes and timeouts; the previous config is kept as config.yaml.prev.

    Share over your Wi-Fi

    Publish the current node list to your local network so a phone or another PC on the same Wi-Fi can subscribe to it. Works only while this program is running.
    Anyone on your Wi-Fi who has this link can see the nodes. Turn sharing off when you are done.
    If the phone cannot connect, allow the program through the Windows firewall (private networks).

    Cloud subscription (GitHub gist)

    Publish the current node list to a secret GitHub gist so any device can subscribe from anywhere. Publishing is manual: a run never uploads anything by itself.
    The token stays in this browser tab and is passed to the local program only for this publish; it is never written to disk. You can also set GITHUB_TOKEN before launching the program.
    Links update after each manual publish. A secret gist is unlisted, not private: anyone with the link can read the nodes.

    Subscription quality

    A slow or laggy node is useless even if it is alive: the last step before the subscription drops everything below these two limits. 0 turns a limit off.
